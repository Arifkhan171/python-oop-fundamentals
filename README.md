# Python OOP Fundamentals

A complete, structured practice repository covering all core Object-Oriented Programming concepts in Python — from classes and objects to abstraction and aggregation.

---

## Topics Covered

| File | Topic | Key Concepts |
|------|-------|-------------|
| 01_classes_and_objects.py | Classes and Objects | class, object, methods, ATM example |
| 02_constructors.py | Constructors | `__init__`, self, default arguments |
| 03_encapsulation.py | Encapsulation | public, protected, private, getter, setter |
| 04_inheritance.py | Inheritance | parent class, child class, super() |
| 05_types_of_inheritance.py | Types of Inheritance | single, multilevel, hierarchical, multiple, hybrid |
| 06_polymorphism.py | Polymorphism | same method, different behavior |
| 07_abstraction.py | Abstraction | ABC, abstractmethod, mandatory methods |
| 08_method_overloading.py | Method Overloading | default args, *args simulation |
| 09_method_overriding_and_super.py | Method Overriding | override, super(), constructor override |
| 10_static_variables_and_methods.py | Static Variables | class variable, @staticmethod |
| 11_aggregation.py | Aggregation | has-a relationship, independent objects |

---

## How to Run

```bash
git clone https://github.com/Arifkhan171/python-oop-fundamentals.git
cd python-oop-fundamentals
python 01_classes_and_objects.py
python 06_polymorphism.py
```
